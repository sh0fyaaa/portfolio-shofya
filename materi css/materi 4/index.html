Tentang

hai, nama saya shofya nasywa, saya mempunyai ketertarikan pada bidang pengembangan web desain. kecintaan saya pada teknologi dan desain dimulai sejak saya menemukan betapa menyenangkannya mengubah ide menjadi tampilan visual yang bisa digunakan dan dinikamati orang banyak. selama beberapa tahun terakhir, saya telah mengerjakan berbagai proyek, saya percaya bahwa kombinasi antara kode yang bersih dan estetika desain yang matang mampu memberikan pengalaman terbaik bagi pengguna.
